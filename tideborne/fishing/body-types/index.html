Tideborne/Fishing/Body Types
Specimen axis

Normal. Giant. Dwarf.

Body Type describes an unusual size class for the specimen. Most fish are Normal; a Body Type event can instead produce a Giant or Dwarf.

The unusual-body event

Body Type begins with a 5% base event chance before the applicable modifiers. If the event does not trigger, the specimen is Normal.

Giant vs. Dwarf is a second decision

If the Body Type event triggers, specimen percentile biases the Giant/Dwarf split smoothly. There is no hard percentile cutoff: Giant remains possible at the low end, Dwarf remains possible at the high end, and the split is exactly balanced at percentile 50.

Perfect CatchA Perfect Catch increases the Body Type event opportunity, but it does not force Giant and does not change the Giant-versus-Dwarf subtype rule.
