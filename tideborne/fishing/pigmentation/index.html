Tideborne/Fishing/Pigmentation
Specimen axis

Rare color, independent roll.

Pigmentation is the rarest of the three standard event-based specimen axes. A notable event can produce Albino or Iridescent while every other trait category continues to resolve independently.

Base notable event1.5%
Albino split70%
Iridescent split30%
Rarity compensationApplies

Event first, subtype second

The system first determines whether Pigmentation is notable. If that event succeeds, the subtype split chooses Albino or Iridescent. Trait Luck changes the notable-event opportunity; it does not rewrite the canonical subtype split.

Presentation follows specimen data

Tideborne's canonical rendering and Journal/item preview paths are built to read persisted specimen pigmentation rather than creating a separate visual-only rarity state.

Trophy valueIridescent is the less common subtype of an already uncommon event, which is why it carries more FishScore trait points than Albino.
