Tideborne/Compatibility
Reference

What Tideborne works with.

Tide 2 is required. Some other fishing and ocean mods are optional.

Tide 2

Tide 2 is the base mod. Tideborne uses its fishing loop, fish data, gear, and Journal systems.

Optional mods

Apex Waters

Tideborne can add support when Apex Waters is installed.

Myths of the Sea

Tideborne can use supported content when the mod is installed.

If an optional mod is not installed, Tideborne should still start without it.

Old worlds and items

Tideborne keeps compatibility data so older items, worlds, and saved information can continue to load after internal changes.

Need an ID?Raw registry IDs are useful for commands and debugging, but normal players usually do not need them.
