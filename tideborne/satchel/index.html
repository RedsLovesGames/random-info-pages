The Angler's Satchel

The Satchel is where Tideborne turns a pile of fish into a manageable collection: store specimens, protect important catches, sort by meaningful traits, upgrade capacity and review records.

Canonical UIThe parchment-style Satchel is the intended Fishing System 2.0 presentation. P10 polished that design rather than replacing it with a newer hidden screen.

Four working areas

Contents

Browse stored specimens, select a catch and act on the selected fish.

Sorting

Create understandable sort rules once the relevant organizer capability is available.

Upgrades

See unlock state, costs, capacity progression and optional prerequisites.

Records

Review canonical FishScore ordering with bounded names, scrolling and visible ranges.

The UI does not own the fish

Satchel storage, capacity, protection, active state, specimen identity, persistence and networking remain server-authoritative. The screen presents and requests actions; it does not synthesize a new client-side specimen.

Built for different screens

P10 added shrink-to-fit rendering for compact windows and inverse coordinate mapping so clicks, hover regions and tooltips remain aligned while the book scales. Keyboard navigation covers tabs, Contents and Records.
