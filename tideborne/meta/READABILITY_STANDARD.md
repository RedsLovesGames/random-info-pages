# Tideborne player-site readability standard

## Audience

Player-facing pages should be understandable to readers with low English proficiency, including readers around EF EPI 450–499 and readers below 450.

This is a writing target, not a score claim about the site.

## Core rules

1. Use short sentences.
2. Put one main idea in each sentence.
3. Prefer common words.
4. Explain game terms the first time they appear.
5. Use direct verbs: `use`, `catch`, `open`, `add`, `keep`, `find`.
6. Avoid long noun phrases.
7. Avoid idioms, jokes and figurative phrases when they carry important meaning.
8. Use numbered steps for actions.
9. Use tables for simple comparisons.
10. Put the simple explanation before exact mechanics.

## Preferred wording

Prefer:

- `Tide 2 is the base mod.`
- `Cast your line.`
- `Wait for a fish.`
- `Right-click when the bar is in the colored area.`
- `A specimen is one fish that you caught.`
- `FishScore is a number from 1 to 3000.`

Avoid:

- `Tideborne extends Tide's equipment language through a persistent specimen-oriented progression layer.`
- `The resulting catch is subsequently enriched by a set of orthogonal specimen axes.`

## Technical words

Some terms must stay because they are names used in the game.

When used on a player page, give a simple meaning:

- **Base mod** — the main mod that another mod builds on.
- **Specimen** — one fish that you caught.
- **Trait** — a special feature of one fish.
- **FishScore** — a number used to compare fish.
- **Gear** — items you use for fishing.
- **Habitat** — the place where a fish can live or be caught.
- **Multiplier** — a number that makes another value bigger or smaller.
- **Percentile** — how large or small a fish is compared with other fish of the same species.

## Page structure

A normal player page should use this order when possible:

1. One-sentence answer.
2. Simple explanation.
3. Steps or pictures.
4. Examples.
5. Exact values or advanced details.
6. Links to related pages.

## Sentence and paragraph target

- Most sentences should be under about 20 words.
- Most paragraphs should be 1–3 sentences.
- Avoid paragraphs that contain several different mechanics.
- Headings should say what the section does, not use clever wording.

## Navigation labels

Use familiar labels such as:

- Getting Started
- Fishing
- Fish
- Gear
- Satchel
- Journal
- Sharks
- Settings
- Help

Do not require players to know project or code names to navigate the site.

## Exact mechanics pages

Exact mechanics can contain formulas and technical values.

They should still include:

- a plain-English summary before the formula;
- a short definition for each variable;
- one worked example when useful;
- a link back to the simple player page.

## Review checklist

Before publishing a player-facing page, check:

- Can a reader understand the first paragraph without knowing Tideborne?
- Are game-specific words explained?
- Are important actions written as steps?
- Can a sentence be made shorter without losing meaning?
- Is the page using current Tide 2/Tideborne behavior rather than old wiki behavior?
- Do images help explain the text rather than only decorate it?
