Fishing Luck

adjustedWeight = baseEncounterWeight × (1 + C_R × sqrt(max(FishingLuck, 0)))

Fishing Luck changes the relative encounter weight of eligible species. The adjusted weights are normalized across the current eligible pool, so a weight multiplier is not the same thing as a final catch probability.

Trait Luck

P_afterLuck = 1 - (1 - P_beforeLuck)^(1 + TraitLuck / 10)

Trait Luck is floored at -10. For standard event axes, the order is base event chance, any axis-specific multiplier, species rarity compensation, Trait Luck, then the final 0 to 1 probability bound.

Perfect Catch

A Perfect Catch adds +10 temporary Trait Luck for that catch and multiplies the Body Type base event chance by 1.25×. Natural percentile and base size are not rerolled.

Perfect Specimen chance after Perfect Catch = 1 - (1 - P_afterLuck)^2

The Quality reward is applied after the percentile curve and Trait Luck. It remains non-guaranteed for ordinary finite probabilities.

Trait Momentum

Trait Momentum is server-owned, per player, and per species. It contributes to the Trait Luck supplied during finalization. Numeric cap and decay values are not published here unless they are separately re-verified against current runtime code.

FishScore

raw = speciesPoints
    + 3 × finalPercentile
    + conditionPoints
    + bodyTypePoints
    + pigmentationPoints
    + qualityPoints

FishScore = round(1 + 2999 × ((raw - 50) / (925 - 50)))
FishScore is clamped to 1..3000

The canonical raw range is 50 to 925 and the mapping is linear.
