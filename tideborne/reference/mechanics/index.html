This page is the compact numerical companion to the player guide. These values follow the current Tideborne 2.0.x specification/source, not outdated values from the preserved legacy Fishing 2.0 web prototype.

Species selection & Fishing Luck

Fishing Luck changes the relative selection weight of eligible species only. After modification, all eligible weights are normalized back into actual selection probabilities.

W′ = W × (1 + C × √max(L, 0)) W = base species weight L = Fishing Luck C = rarity coefficient

Weight ≠ probabilityA 2× relative weight multiplier does not mean a final 2× catch probability; the entire eligible pool is normalized together.

Rarity compensation

Body Type, Condition and Pigmentation receive species-rarity compensation before Trait Luck. Quality intentionally does not.

Body Type

Body Type starts from a 5% event chance. On a Perfect Catch, the event chance receives ×1.25 before rarity compensation and Trait Luck. If the event succeeds, the pre-body specimen percentile smoothly chooses the conditional Giant/Dwarf split.

Condition

Base notable-condition event = 5% Then rarity compensation Then Trait Luck Then Prismarine Bobber final-event ×1.10 if applicable If event succeeds: Scarred = 65% Parasite-Ridden = 35%

Pigmentation

Prismarine Bobber modifier

The Prismarine Bobber applies a +10% final event multiplier (×1.10) to Body Type, Condition and Pigmentation after the standard event math. It does not replace rarity compensation or Trait Luck, and it does not apply to the Perfect Specimen quality curve.

Trait Momentum

Trait Momentum is optional server-authoritative bad-luck protection tracked per player and per species. The frozen design specifies roughly +1 Momentum for a fully normal catch, a cap of about 15, a substantial reduction when that species produces a notable specimen, and Momentum contributing temporary Trait Luck to future catches of that species.

Precision noteThe current frozen specification describes the notable-catch response as a substantial reduction rather than freezing a universal “always reset to zero” rule. The wiki therefore does not claim an exact reset value until that persistence policy is explicitly frozen in current source/config.
