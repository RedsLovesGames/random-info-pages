How the model works & references

This is a 2D incompressible flow model in a closed tank. Each step moves velocity and dye along the flow, smooths velocity according to viscosity, and solves for a pressure correction to reduce compression. The velocity view shows speed. Vorticity shows how quickly the fluid rotates locally.

The controls use relative values and the pressure display shows the solver’s correction. In the jet presets, the colored sources push fluid already in the tank.

  • Pavel Dobryakov’s WebGL Fluid Simulation inspired the interactive dye brush.
  • Jérémie Piellard’s Navier–Stokes demo inspired the field views and obstacle.
  • Mark Harris’s Fast Fluid Dynamics Simulation on the GPU describes the Stable Fluids method used as the solver reference.
