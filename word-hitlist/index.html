      How to play
      1. Create a room and share the invite link or the six-character code. A room needs 2 to 12 players.
      2. Everybody gets the same letters and three goals each round. Select a goal, then type or tap letters to spell an answer.
      3. Each tile can be used once in a word. Use a different word for each goal. Answers use the site’s Towers of Babble dictionary.
      4. Each cleared goal earns 100 points. Answers are revealed when time runs out. The highest total score wins. Ties share the win.

      Tile values for high-score goals: A, E, I, L, N, O, R, S, T, U = 1 · D, G = 2 · B, C, M, P = 3 · F, H, V, W, Y = 4 · K = 5 · J, X = 8 · Q, Z = 10.
