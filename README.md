# random-info-pages

Standalone GitHub Pages utilities and reference pages.

- [Wheel](https://redslovesgames.github.io/random-info-pages/wheel/) - simple customizable random picker with weighted entries, local saves, sharing, and multiple wheels.
- [Old Ass Politic](https://redslovesgames.github.io/random-info-pages/oldasspolitic/) - interactive U.S. House and Senate age/party seat map.
- [Tideborne Fishing System 2.0](https://redslovesgames.github.io/random-info-pages/tide2/) - interactive fishing-system reference and calculators.
- [School Schedule](https://redslovesgames.github.io/random-info-pages/school-schedule/) - interactive Fall 2026 school schedule and checklist dashboard.

- [Political Grid](https://redslovesgames.github.io/random-info-pages/political-grid/) - interactive 100-statement checklist with shared aggregate analytics.

- [A Day in Messages, 9/11 timeline](https://redslovesgames.github.io/random-info-pages/9-11-timeline/) - source-linked September 11 chronology with a 24-hour playback; pager volume data not yet ingested.
