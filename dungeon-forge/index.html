Scene Importer fills fog and adds walls when it creates a new scene.

Import into Owlbear Rodeo
  1. Install Dynamic Fog and Scene Importer, then enable them in your room.
  2. Open Scene Importer, select the downloaded file, keep wall import enabled and choose Create New Scene.
  3. Enable fog preview and add a primary light to a player token so vision follows it. Room torches are secondary lights when the importer is set to Auto.

Reveal entrance adds a stationary 10-foot primary light. You can remove it after assigning token vision.

You can also add the grid-aligned player PNG as a regular map and use manual fog.
