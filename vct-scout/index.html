Observed data: VCT compositions, map results, pick frequencies, side results, and team comparisons come from the site's VLR-backed snapshot.

Tactical references: each current map points to an exact 2026 VCT match on RIB. Where a map-specific VOD timestamp is verified, the board also links directly to that map. RIB exposes Replay as an in-page tab, so the UI no longer labels the match URL as a direct Replay permalink.

Map placement: named callouts are converted from VALORANT map metadata into minimap positions. Site letters such as A, B, and C are treated as meaningful parts of a callout so A Main, B Main, A Site, and B Site cannot collapse onto the same location.

Important boundary: the named plays, route arrows, and utility plans are planning templates unless a specific round is explicitly identified. ValoPlant exact replay links are only shown when a particular shared .vrf replay exists, so the generic ValoPlant landing-page button has been removed.
